# Container Loading Simulator

컨테이너에 박스 또는 팔레트 화물을 배치하고 3D로 검토하는 웹 기반 적재 시뮬레이터입니다.

## 현재 버전

`v2.4.0`

## 주요 기능

- 박스 단독 적재 / 팔레트 적재 모드 통합
- CBM·중량을 고려한 안쪽 우선 후보 생성
- 동일 품목 우선 적재 후 잔량 혼합 적재
- 박스 90도 회전 허용/금지 및 자동 방향 선택
- 최소 지지면·무게중심 지지 조건을 포함한 후보 생성
- 최대 적층단과 상부 허용중량 검사
- 컨테이너 최대 적재중량 검사
- 충돌·벽·천장·바닥 침범 검증
- **Rapier 3D deterministic 기반 실제 물리 안정성 종합검증**
- 정적 중력 / 출발 가속 0.30g / 급제동 0.50g / 횡가속 0.35g 시나리오 비교
- 박스별 수평 이동량·높이 변화·기울기·잔류 속도 판정
- 물리 안정성 100점 점수와 안정/주의/불안정 분류
- 팔레트 바닥판을 자체 중량의 동적 강체로 모델링해 팔레트 적층 안정성 검사
- 팔레트 전역 최적화: 1~3단 후보, 바닥 점유, 팔레트 수, 좌우 균형 비교
- 저활용률 팔레트 배치의 컨테이너 길이 활용 및 폭 중앙 정렬
- 반복 팔레트 병합(consolidation)
- 팔레트 위 화물 중앙 정렬 및 우클릭 3D 미니 프리뷰
- 박스/팔레트 모드 공통 4면 박스정보 스티커와 상시 외곽선
- 무게중심 및 적재 품질 평가
- 행·열·단 위치 체계와 안쪽/중앙/문쪽 구역 표시
- 최대 적재율 / 안정성 / 하역 편의 전략 비교
- 다중 컨테이너 자동 분할 계획 및 빈 공간 추가 적재 추천
- 개별 박스·그룹 수동 이동, 스마트 스냅, 실행취소, 자동 배치 복귀
- 작업 순서 생성 및 재생, 작업자 도달 높이·취급 중량 인체공학 점검
- 엑셀 템플릿 다운로드 및 일괄 업로드
- Excel 업로드 즉시 화면 반영
- 브라우저 로컬 저장/불러오기

## 물리 안정성 검증

자동 적재 결과를 Rapier 3D 월드에 복제하여 강체 시뮬레이션으로 재검증합니다. 적재 알고리즘의 결과 좌표를 임의로 바꾸지 않고, 중력과 운송 가속 조건에서 배치가 유지되는지 별도로 평가합니다.

검증 시나리오:

1. **정적 중력** — 적재 직후 낙하·기울어짐 확인
2. **출발 가속 0.30g** — 차량이 앞으로 출발할 때 후방 관성 방향 이동·전도 확인
3. **급제동 0.50g** — 반대 방향 관성에 의한 전후 미끄러짐 확인
4. **횡가속 0.35g** — 좌우 코너링 시 측면 미끄러짐·전도 위험 확인

검사 항목:
- 박스별 수평 이동 거리
- 초기 높이 대비 낙하/상승 변화량
- 박스 기울기 각도
- 시뮬레이션 종료 시 선속도·각속도
- 컨테이너 경계 이탈 여부
- 안정 / 주의 / 불안정 분류 및 종합 안정성 점수
- 팔레트 모드의 팔레트 바닥판 이동·기울기

> 0.30g / 0.50g / 0.35g 값은 적재안 비교를 위한 기본 시뮬레이션 조건이며 법적 기준을 의미하지 않습니다.

## 팔레트 적재

팔레트 모드는 팔레트별 적재수량을 만든 뒤 1~3단 적층 후보를 비교하고, 적재수량 보존 → 바닥 점유 열 최소 → 팔레트 수 최소 → 좌우 중량 편차 최소 순으로 후보를 비교합니다. 저활용률 배치는 컨테이너 길이를 활용하되 폭 방향 팔레트 그룹 전체를 중앙에 맞추며, 상자는 각 팔레트 중심에 정렬됩니다.

팔레트 우클릭 정보창에서는 해당 팔레트와 화물만 별도 3D 캔버스로 회전/확대해 확인할 수 있습니다.

## 박스 정보 표시

박스정보 ON 상태에서는 박스 단독 적재와 팔레트 적재 모두 각 상자의 앞·뒤·좌·우 4개 세로 면에 정보 스티커를 표시합니다. 스티커는 면에 밀착해 렌더링하되 카메라 각도에 따른 z-fighting을 줄이기 위해 미세한 표면 오프셋과 polygon offset을 사용합니다.

## 엑셀 업로드

템플릿은 화면의 엑셀 양식 기능에서 받을 수 있습니다. 주요 열은 코드, 이름, 길이, 폭, 높이, 중량, 수량, 최대 적층단, 상부 허용중량, 90도 회전 허용 여부입니다. 업로드 성공 후 앱 상태가 즉시 갱신됩니다.

## 작업지시서

박스 적재 결과에서 작업지시서를 생성할 수 있으며 컨테이너 규격, 적재수량/중량/체적 적재율, 제약조건, 품목별 요청/적재/잔량, 미적재 사유, 현장 안전 경고를 포함합니다. 물리 검증이 최신 적재안에 대해 유효하지 않은 경우 확인 절차와 미검증 표시가 적용됩니다.
