# Container Loading Simulator

컨테이너에 박스 또는 팔레트 화물을 배치하고 3D·현장 작업지시·관성 시뮬레이션으로 검토하는 웹 기반 적재 시뮬레이터입니다.

## 현재 버전

`v2.6.0`

## 주요 기능

- 박스 직접적재 / 팔레트 적재 모드 통합
- SKU 총 CBM → 총중량 → 개당중량 기반 안쪽 우선 배치
- 동일 품목 완성 세로 스택 우선, 잔량은 문쪽 최종 혼합적재 구역에서만 처리
- 혼합 잔량이 순수 SKU 블록 사이로 다시 침투하지 않도록 구역 경계 고정
- 박스 90도 회전 허용/금지 및 자동 방향 선택
- 최소 지지면·무게중심 지지 조건을 포함한 후보 생성
- 최대 적층단과 상부 허용중량 검사
- `maxTopLoadKg`는 값이 있는 품목에만 적용
- 컨테이너 최대 적재중량 및 포장/보조자재 중량 검사
- 충돌·벽·천장·바닥·팔레트 슬롯 침범 방지
- 팔레트 품목 총 물량중량 우선, 동일 품목 선적 후 최종 consolidation
- 팔레트 위 화물 점유영역 자동 중앙정렬
- 설정된 팔레트 적층단·상부지지·팔레트 면적지지 조건 적용
- 실제 슬롯이 없는 추가 팔레트는 겹치지 않고 `미적재`로 반환
- Rapier 3D deterministic 기반 물리 안정성 검증
- 출발 가속 0.30g / 급제동 0.50g / 횡가속 0.35g 관성 시나리오
- **최종 결과 관성 인증 게이트**: 3종 PASS 이후에만 최종 결과 공개
- 기본 적재 실패 시 필요한 수준까지 자동 보강 후 재시험
- 밴딩·랩핑·미끄럼방지·블로킹·고정바를 실제 별도 구속력으로 모델링
- 팔레트 화물↔팔레트 상대 미끄럼과 팔레트↔하부 지지체 상대 이동 별도 판정
- 보조자재 3D 시각화 및 현장 단위중량 설정
- 박스/팔레트 작업지시서와 Excel 결속 BOM 연동
- 팔레트별 밴딩/각대/랩핑/미끄럼방지재 수량 및 작업 순서
- Excel `보조자재`, `관성보강이력`, `관성안전지표`, `팔레트별결속` 출력
- 작업 순서 생성/재생, 수동 이동, 스마트 스냅, 실행취소
- 다중 컨테이너 계획, 빈 공간 추가 적재 추천
- 모바일 반응형 UI 및 대량 화물 InstancedMesh 렌더링
- 전역 Error Boundary 및 Vercel 정적 배포 설정

## v2.6.0 핵심 변경

### 박스 직접적재 순서 고정

박스 품목은 기본적으로 다음 순서로 처리합니다.

1. SKU별 총 CBM 내림차순
2. SKU별 총중량 내림차순
3. 개당 중량 내림차순

컨테이너 가장 안쪽부터 같은 품목의 세로 스택을 허용 높이까지 완성한 뒤 다음 위치로 이동합니다. 마지막 수량이 완성 스택을 만들지 못하면 순수 적재 구역에 낮은 더미를 만들지 않고 보류합니다.

모든 순수 SKU 블록이 끝난 위치를 혼합적재 시작 경계로 고정하고, 보류 잔량은 그 경계보다 문쪽에서만 적재합니다. 후처리 형상 정리도 완성 스택을 해체하거나 혼합 화물을 다시 안쪽으로 되돌리지 않습니다.

### 팔레트 적재 규칙

팔레트용 품목은 다음 순서로 처리합니다.

1. 품목별 총 물량중량 내림차순
2. 품목별 총 CBM 내림차순
3. 개당 중량 내림차순
4. 코드순

1차 적재는 같은 품목끼리 팔레트를 채웁니다. 모든 품목의 순수 적재가 끝난 뒤, 후순위 팔레트의 전체 잔량을 기존 팔레트에 안전하게 옮겨 실제 팔레트 수를 줄일 수 있을 때만 혼합 병합합니다.

팔레트 위 화물은 적재가 끝난 후 점유영역 전체를 팔레트 중심에 맞춰 이동해 한쪽 몰림을 줄입니다. 팔레트 적층은 사용자가 설정한 `maxStackLevels`를 그대로 상한으로 사용하며, 실제 컨테이너 높이와 하부 화물 상부 허용중량·면적 지지를 동시에 통과해야 합니다.

활성화된 각대/랩핑은 최종 포장 후 최대중량을 넘지 않도록 새 팔레트 생성 시 보수적으로 가능한 중량을 미리 예약합니다.

## v2.5.0 핵심 변경

### 최종 결과 잠금

자동 적재 후 바로 결과를 공개하지 않습니다. 현재 배치를 대상으로 출발 가속, 급정거, 급회전 관성 검증을 수행하고 3종을 모두 통과한 경우에만 최종 결과를 엽니다. 적재 좌표나 보조자재 단위중량이 바뀌면 이전 PASS는 무효화됩니다.

### 물리 결속 모델

보강 단계 숫자로 이동값을 임의 감소시키지 않고, 강체에 운송 관성력을 그대로 적용한 뒤 보조재를 별도의 스프링-댐퍼 복원력/감쇠력으로 모델링합니다.

팔레트 모드 내부 PASS 기준:

- 최대 전체 수평 이동 ≤ 12 mm
- 최대 기울기 ≤ 1.8°
- 화물↔팔레트 상대 미끄럼 ≤ 8 mm
- 팔레트↔컨테이너 또는 상단 팔레트↔하단 팔레트 상대 이동 ≤ 12 mm

밴딩/랩핑은 화물을 자기 팔레트 기준으로 구속합니다. 다단 팔레트는 바로 아래 지지체를 기준으로 상대 이동을 계산하며, 컨테이너 공통 고정바의 직접 구속력은 바닥 팔레트에 적용합니다.

> 위 기준과 구속력 수치는 시뮬레이터 내부 비교 기준이며 실제 운송 안전 인증 또는 자재 제조사 정격을 의미하지 않습니다.

## 배포 전 검증

기본 배포 전 검증:

```bash
npm install
npm audit --audit-level=high
npm run verify:predeploy
```

`verify:predeploy`는 단위/회귀 테스트 → TypeScript+Vite production build → 번들 예산 검사를 순서대로 실행합니다.

브라우저 E2E:

```bash
npx playwright install chromium
npm run test:e2e
```

브라우저 환경까지 준비되어 있으면 전체 검증:

```bash
npm run verify:full
```

Production 반영 전에는 반드시 `PREDEPLOY_V2_6.md`를 완료합니다.

## 물리 검증 구조

이 프로젝트에는 두 종류의 물리 검증 흐름이 있습니다.

1. **종합 물리 안정성 검증** — 정적 중력과 운송 가속 조건에서 강체 지지·낙하·기울기·잔류 운동 등을 검토합니다.
2. **최종 관성 인증** — 최종 결과 공개 직전 출발 가속/급정거/급회전을 시험하고, 실패하면 고정 보조재를 단계적으로 추가해 재시험합니다.

최종 관성 인증은 현재 적재 좌표와 보조자재 설정을 포함한 signature로 관리하여 다른 적재안의 과거 PASS가 재사용되지 않도록 합니다.

## 작업지시서

### 박스 직접적재

작업자가 기술 상세표를 읽지 않아도 되도록 필수 정보 위주로 구성합니다.

- 위에서 본 적재도
- 옆에서 본 적재도
- 3단계 진행 그림
- 동일 작업 블록 그룹 번호/수량
- 안쪽부터 / 바닥부터 / 번호 순서대로 작업 지시
- 필요한 보조자재와 최종 체크박스

### 팔레트

- 위/옆 적재도
- P번호 / C번호 / 적층단 연동
- 팔레트 투입 순서
- `미끄럼방지 → 배치 → 각대 → 밴딩 → 랩핑 → 확인`
- 모든 팔레트 배치 후 공통 고정바 작업
- 자동 보강 이력과 관성 안전지표

작업지시서는 현재 적재안과 일치하는 최종 관성 PASS가 있어야 출력할 수 있습니다.

## 운영 안정성

- 적재 로직은 `src/engine`과 UI를 분리
- 알고리즘 변경 시 회귀 테스트 동반
- 화물/컨테이너/모드/보조자재 변경 시 이전 인증 무효화
- 컨테이너 물리 슬롯을 초과한 팔레트를 겹쳐 표시하지 않고 미적재 처리
- 예기치 않은 React 렌더링 오류는 Error Boundary 복구 화면으로 처리
- 실제 현장 적용 전 박스 압축강도, 팔레트 상태/허용하중, 바닥 집중하중, 축중, 결속재 규격/정격, 작업 안전기준 별도 확인
