# Container Loading Simulator

컨테이너에 박스 또는 팔레트 화물을 배치하고 3D로 검토하는 웹 기반 적재 시뮬레이터입니다.

## 현재 버전

`v2.2.0`

## 주요 기능

- 박스 단독 적재 / 팔레트 적재 모드 통합
- CBM·중량을 고려한 안쪽 우선 적재
- 동일 품목 우선 적재 후 잔량 혼합 적재
- 낮은 행(대표 높이 50% 미만 또는 사실상 1단)을 문쪽 마지막 혼합 구역으로 후순위 이동
- 중앙 낱개, 돌출 구역, 동일 품목 분산 형상 감지 및 후처리 최적화
- 박스 90도 회전 허용/금지 및 자동 방향 선택
- 최대 적층단과 상부 허용중량 검사
- 컨테이너 최대 적재중량 검사
- 충돌·벽·천장·바닥 침범 검증
- **Rapier 3D 기반 실제 중력·충돌·마찰 안정성 검증**
- 물리 검증 후 박스별 수평 이동량·높이 변화·기울기·잔류 속도 판정
- 물리 안정성 100점 점수와 안정/주의/불안정 분류
- 물리 검증 이상 위치를 클릭해 기존 3D 뷰에서 해당 박스 즉시 선택
- 무게중심 및 적재 품질 평가
- 행·열·단 위치 체계와 안쪽/중앙/문쪽 구역 표시
- 팔레트 최소화, 2~3단 적층, 좌우 중량 균형
- 각대·랩핑 및 포장재 최소 사용 최적화
- 최대 적재율 / 안정성 / 하역 편의 전략 비교
- 다중 컨테이너 자동 분할 계획 및 빈 공간 추가 적재 추천
- 개별 박스·그룹 수동 이동, 스마트 스냅, 실행취소, 자동 배치 복귀
- 작업 순서 생성 및 재생, 작업자 도달 높이·취급 중량 인체공학 점검
- 엑셀 템플릿 다운로드 및 일괄 업로드
- Excel 업로드 즉시 화면 반영(페이지 새로고침 불필요)
- 브라우저 로컬 저장/불러오기
- 전체 초기화 전 사용자 확인 절차

## 물리 안정성 검증

자동 적재를 실행한 뒤 상단의 `물리 검증`을 누르면 현재 적재 좌표를 Rapier 3D 월드에 그대로 복제합니다. 이 검증은 적재 알고리즘이 만든 좌표를 임의로 바꾸지 않고, 실제 중력·충돌·마찰을 적용했을 때 그 배치가 유지되는지를 별도로 확인합니다.

검사 항목:
- 박스별 수평 이동 거리
- 초기 높이 대비 낙하/상승 변화량
- 박스 기울기 각도
- 시뮬레이션 종료 시 선속도·각속도
- 컨테이너 경계 이탈 여부
- 안정 / 주의 / 불안정 분류 및 종합 안정성 점수

불안정 또는 주의 항목을 선택하면 해당 배치 인덱스를 기존 3D 선택 시스템에 전달해 문제 박스를 바로 확인할 수 있습니다. Rapier 모듈은 동적 import로 불러와 초기 대시보드 번들에 물리엔진을 강제로 포함하지 않습니다.

## 엑셀 업로드

템플릿은 화면의 `엑셀 양식` 버튼에서 받을 수 있습니다. 주요 열은 코드, 이름, 길이, 폭, 높이, 중량, 수량, 최대 적층단, 상부 허용중량, 90도 회전 허용 여부입니다.

회전 허용 값은 `Y/N`, `허용/금지`, `TRUE/FALSE`, `1/0`을 인식합니다. 업로드 성공 후 앱 상태가 즉시 갱신되므로 페이지를 다시 열 필요가 없습니다.

## 3D 현장 검토

- X축: 컨테이너 안쪽 → 문쪽
- Y축: 좌측 → 우측
- Z축: 바닥 → 천장
- 무거운 화물과 팔레트는 안쪽 및 낮은 위치를 우선합니다.
- 완성도가 낮은 저층 행은 앞/중앙에 남기지 않고 가능한 경우 문쪽 마지막 혼합 구역으로 이동합니다.
- 3D의 박스를 클릭하면 해당 박스가 강조되고 행/열/단, 구역, XYZ 위치와 실제 치수/중량을 확인할 수 있습니다.

## 작업지시서

박스 적재 모드에서 상단 `작업지시서` 버튼을 누르면 현재 결과 기준의 인쇄용 새 창을 생성합니다.

포함 정보:
- 컨테이너 규격 및 최대중량
- 적재수량 / 적재중량 / 체적 적재율
- 적재 품질점수 / 좌우·앞뒤 편차
- 품목별 요청수량 / 적재수량 / 잔량
- 미적재 수량과 사유
- 현장 안전 검증 경고

브라우저 인쇄 기능을 이용해 종이 출력 또는 PDF 저장이 가능합니다.

## 성능 기준

- 3D 모듈은 초기 화면과 분리해 지연 로딩합니다.
- Rapier 물리엔진도 사용자가 물리 검증을 실행할 때 동적으로 로딩합니다.
- 박스와 팔레트 화물은 품목별 `InstancedMesh`로 묶어 draw call을 줄입니다.
- Canvas DPR을 제한해 고해상도 모바일 기기의 GPU 부하를 완화합니다.
- 물리 검증은 화물 수량에 따라 시뮬레이션 step 수를 조정하고 일정 step마다 UI 스레드에 제어권을 반환합니다.
- 40ft급 다품목 혼합 적재 스트레스 테스트를 유지합니다.
- 초기 메인 JS는 CI 재활성화 후 800 KiB 상한으로 자동 검증합니다.

## 운영 안정성

- 예기치 않은 React 렌더링 오류가 발생하면 흰 화면 대신 복구 화면을 표시합니다.
- 복구 화면에서 새로고침 또는 브라우저 로컬 데이터 초기화를 선택할 수 있습니다.
- 화물 전체 초기화는 사용자 확인 후에만 수행됩니다.
- npm high 이상 취약점 감사, production build, 번들 예산, 브라우저 E2E가 9월 CI 자동 검증 대상으로 준비되어 있습니다.
- 8월 수동 검수 기준은 `MANUAL_QA.md`를 사용합니다.

## v2.2.0 완료 기준

v2.2.0은 기존 v2.1 운영형 기능 기준선에 Rapier 기반 실제 물리 안정성 검증을 결합한 버전입니다. 적재 알고리즘의 정적 제약 검사와 별개로, 생성된 적재안이 중력·충돌·마찰 환경에서 유지되는지 확인할 수 있습니다.

실제 현장 적용 전에는 회사별 박스 압축강도, 팔레트 규격, 바닥 허용하중, 차량/컨테이너 축중, 고정·결박 방식, 차량 가감속·진동 및 작업 안전 기준을 별도로 검증해야 합니다. 시뮬레이터 결과는 작업 의사결정 보조 자료이며 현장 안전 검증을 대체하지 않습니다.

## 배포

`vercel.json`에 Vite build(`npm run build`), `dist` 출력 디렉터리, SPA rewrite, 해시 assets 장기 캐시 정책이 포함되어 있습니다. Vercel에서 이 GitHub 저장소를 프로젝트로 연결하면 정적 웹앱으로 배포할 수 있습니다.

9월 CI 재활성화 후 성공한 `main` 실행에서는 `container-loading-simulator-dist` 아티팩트를 다시 자동 생성하도록 준비되어 있습니다.

## 개발 원칙

변경 내역은 `CHANGELOG.md`, 배포 절차는 `DEPLOYMENT.md`, 수동 검수는 `MANUAL_QA.md`, 9월 CI 재가동은 `SEPTEMBER_CI.md`를 참고하세요.
