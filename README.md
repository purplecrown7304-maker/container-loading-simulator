# Container Loading Simulator

컨테이너에 박스 또는 팔레트 화물을 배치하고 3D로 검토하는 웹 기반 적재 시뮬레이터입니다.

## 현재 버전

`v1.0.0`

## 주요 기능

- 박스 단독 적재 / 팔레트 적재 모드 통합
- CBM·중량을 고려한 안쪽 우선 적재
- 동일 품목 우선 적재 후 잔량 혼합 적재
- 낮은 행(대표 높이 50% 미만 또는 사실상 1단)을 문쪽 마지막 혼합 구역으로 후순위 이동
- 중앙 낱개, 돌출 구역, 동일 품목 분산 형상 감지 및 후처리 최적화
- 박스 90도 회전 허용/금지 및 자동 방향 선택
- 최대 적층단과 상부 허용중량 검사
- 컨테이너 최대 적재중량 검사
- 충돌·벽·천장·바닥 침범 검증
- 무게중심 및 적재 품질 평가
- 행·열·단 위치 체계와 안쪽/중앙/문쪽 구역 표시
- 팔레트 최소화, 2~3단 적층, 좌우 중량 균형
- 각대·랩핑 및 포장재 최소 사용 최적화
- 엑셀 템플릿 다운로드 및 일괄 업로드
- 브라우저 로컬 저장/불러오기
- 모바일 반응형 UI

## 기술 스택

- React
- TypeScript
- Vite
- Three.js / React Three Fiber / Drei
- Vitest
- SheetJS (`xlsx` 0.20.3 공식 배포본)
- GitHub Actions

## 실행 방법

```bash
npm install
npm run dev
```

## 검증

```bash
npm test
npm run build
```

또는 한 번에:

```bash
npm run check
```

`main` 브랜치에 push하거나 Pull Request를 만들면 GitHub Actions가 자동으로 설치, 테스트, TypeScript/Vite production build를 실행합니다. `main`의 성공한 push에서는 검증된 `dist` 결과물을 Actions artifact로 14일간 보관합니다.

## 자동 테스트 범위

- 박스 충돌 및 컨테이너 경계
- 컨테이너 최대 적재중량
- 박스 최대 적층단
- 박스 상부 허용중량
- 박스 회전 허용/금지
- 소수 치수 exact-fit 계산
- 다품목 대량 혼합 적재 회귀/성능
- 중앙 낱개·돌출·품목 분산 형상 품질
- 형상 후처리 안전성
- 낮은 행 문쪽 이동 규칙
- 팔레트 포함 총중량
- 팔레트 최대 적층단
- 팔레트 위 박스 회전 및 exact-fit

## 엑셀 업로드

템플릿은 화면의 `엑셀 양식` 버튼에서 받을 수 있습니다. 주요 열은 코드, 이름, 길이, 폭, 높이, 중량, 수량, 최대 적층단, 상부 허용중량, 90도 회전 허용 여부입니다.

회전 허용 값은 `Y/N`, `허용/금지`, `TRUE/FALSE`, `1/0`을 인식합니다.

## 적재 방향 기준

- X축: 컨테이너 안쪽 → 문쪽
- Y축: 좌측 → 우측
- Z축: 바닥 → 천장
- 무거운 화물과 팔레트는 안쪽 및 낮은 위치를 우선합니다.
- 완성도가 낮은 저층 행은 앞/중앙에 남기지 않고 가능한 경우 문쪽 마지막 혼합 구역으로 이동합니다.

## v1.0.0 완료 기준

v1.0.0은 핵심 적재 엔진, 팔레트 모드, 3D 검토, 엑셀 입력, 형상/무게중심 평가, 회귀 테스트와 CI production build가 하나의 안정화 기준선에서 통과하는 버전입니다. 실제 현장 적용 전에는 회사별 박스 압축강도, 팔레트 규격, 차량/컨테이너 축중 및 작업 안전 기준을 별도 검증해야 합니다.

## 개발 원칙

적재 로직은 UI와 분리된 `src/engine`에서 관리합니다. 새 적재 규칙을 추가하거나 수정할 때는 기존 제약을 깨지 않는 회귀 테스트를 함께 추가합니다.
