# AirSup 상호작용 관찰 기록

2026-11-17 사용자 요청에 따라 [AirSup Cargo Load](https://www.airsup.ai/lab/cargo-load)를
Chrome에서 직접 조작한 기록이다. 정적 화면만 보거나 소스 번들을 분석해 동작을
추정한 기록이 아니다. 관찰 화면은 참고 사이트이며 이 저장소의 구현 결과 화면이 아니다.

작업 공간의 관찰 산출물: `outputs/staging-yard-qa/airsup-observed-reference.jpg`.
이 파일은 시뮬레이터 저장소 옆의 QA 산출물 디렉터리에 있으며, 저장소 루트를 기준으로는
`../staging-yard-qa/airsup-observed-reference.jpg`이다. 화면에 표시된 날짜·시각과 수치는
참고 사이트의 데모 상태이며 관찰 일시나 우리 적재 결과로 취급하지 않는다.

## 직접 확인한 범위

| 조작 | 관찰한 내용 |
| --- | --- |
| `3D` / `Top` | 해당 시점 버튼을 직접 사용했다. |
| 장면 드래그 | 장면을 회전하는 Orbit 조작을 직접 사용했다. |
| 마우스 휠 | 장면 확대·축소를 직접 사용했다. |
| `Load at dock` | 버튼을 누른 뒤 지게차와 화물의 이동 연출을 확인했다. |
| `Skip` | 버튼을 누르고 나머지 시퀀스를 빠르게 진행한다는 토스트를 확인했다. |

관찰 화면에는 차량·대기 화물·지게차가 같은 도크 장면에 있고, 차량 목록과 적재 요약,
하중·분포 카드, 주문 표가 함께 표시되었다. 이런 화면 구성이 보였다는 사실과 그 수치가
물리적으로 검증되었다는 주장은 별개다.

## 확인하지 않은 내용

- 차량 항목도 조작했지만 당시 연출이 진행 중이어서 선택한 차량의 모델·규격·요약이
  실제로 갱신됐는지는 끝까지 검증하지 않았다. 차량 전환 기능을 검증했다고 보고하지 않는다.
- AirSup의 정확한 카메라 전환 시간·보간식, Orbit damping·속도·줌 한도, 조명·노출·
  그림자·재질·AO 파라미터는 확인하지 않았다.
- 지게차 동작이 실제 적재 엔진·충돌·지지·하중·물리 인증과 어떻게 연결되는지 확인하지
  않았다. 표시된 하중이나 `LEGAL` 같은 상태를 우리 엔진의 안전 판정과 동일시하지 않는다.
- 성능·렌더러·네트워크 자산 크기를 측정하거나 우리 제품과 속도·품질 우열을 비교하지 않았다.

## 이 저장소에 반영하는 범위

참고 대상은 장면을 살펴보는 상호작용의 일관성이다. 우리 카메라 설정은 기존 Three
뷰어와 대기장 데이터 경계에 맞춰 별도로 설계하며 AirSup의 내부 설정을 재현했다고
주장하지 않는다.
매끄러운 전환의 적용 범위는 메인 대기장 작업 화면이다. 비교 진단·벤치마크·관성 재생의
즉시 시점 정렬 경로와 구분한다.

| 우리 설계 | 범위 |
| --- | --- |
| 명시적 시점 전환 | 375ms 보간은 우리 제품의 독립 설정값이다. |
| 직접 Orbit 조작 | 사용자가 조작을 시작하면 진행 중인 시점 보간을 취소한다. |
| 대기 화물 드래그 | 기존처럼 카메라 조작을 잠가 화물 이동과 회전을 분리한다. |
| 동작 줄이기 | reduced-motion 설정에서는 시점을 즉시 적용한다. |
| 첫 장면 맞춤 | 처음 맞추는 장면은 기다림 없이 즉시 배치한다. |
| 일반 데이터 갱신 | 화물·선택·품질·구역 수량 갱신만으로 사용자의 시점을 자동 초기화하지 않는다. |

위 표는 우리 구현의 설계 범위이며 참고 사이트에서 측정한 값이 아니다. 최종 동작은
`cameraMotion.ts`와 `ThreeComparisonScene.tsx`의 회귀 검사·실제 작업 화면 E2E에서 확인한다. 지게차나 화물을 이동시키는
참고 사이트의 애니메이션은 이번 작업에 이식하지 않는다.

AirSup의 소스·번들·모델·텍스처를 별도로 추출·다운로드하거나 프로젝트에 복사하지 않았다. 기존 프로젝트의
자산과 독립적인 카메라 제어를 사용한다. 표시 전환·조명·연출은 적재 수량·좌표·중량·
제약 검사·저장 계획·운송 인증을 변경하지 않는다는 [대기장 기능 경계](../features/STAGING_YARD.md)를 유지한다.
