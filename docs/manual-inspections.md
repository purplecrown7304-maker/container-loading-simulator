# 적재 결과 직접 점검

자동 적재 후 **메뉴 → 점검 → 적재 결과 점검**에서 원하는 항목을 실행합니다.
점검은 배치를 바꾸거나 작업지시서를 승인하지 않습니다. 실제 운송 안전 인증이 아닙니다.

| 항목 | 재사용하는 계산 | 범위와 제한 |
| --- | --- | --- |
| 경계·충돌 | `validatePlacements` | 상자와 팔레트 바닥판의 직육면체 경계·겹침. 지지·적층·누적 상부하중은 이 항목에 포함되지 않음 |
| 무게중심 | `assessWeightBalance` | 상자 중량과 팔레트 바닥판 자중을 한 번씩 포함. 좌표·편차만 표시하며 등급을 운송 안전 판정으로 사용하지 않음 |
| 총중량·바닥 하중 추정 | `analyzeFloorLoad` | 적재중량 한계 비교, 12×4 격자 투영 추정. 바닥 기준이 없으면 비교 미실행. 발 접촉압·지지 전달하중·차량 축하중은 계산하지 않음 |
| 관성 테스트 | `runInertiaAnimation` | 출발 0.30g, 급제동 0.50g, 급회전 0.35g. 동일 대상의 기존 결속 결과 또는 기존 엔진 기본 결속 조건 사용. 최대 이동·기울기·계산 시간을 표시 |

팔레트 모드도 `PhysicsTarget`의 상자와 별도 바닥판을 그대로 사용합니다. 원본 좌표, 자동 적재 알고리즘, 모델 자산, 저장 데이터는 바꾸지 않습니다.

계산은 Web Worker에서 실행합니다. 한 번에 하나만 실행할 수 있고 **실행 취소**, **닫기**, Escape 또는 브라우저 뒤로 가기는 실행을 종료하고 늦은 응답을 폐기합니다. 입력·장비·결속 조건·적재 대상이 바뀌면 이전 점검 결과도 폐기합니다. 다시 열 때 과거 `window` 적재 결과를 우회 복구하지 않습니다. 유효한 결과가 없으면 자동 적재를 먼저 실행해야 합니다.

3D는 Three.js가 기본이며 기존 8개 Meshy 모델을 사용합니다. 뷰어 상단 **Unity** 또는 `?renderer=unity`로 기존 Unity에 복귀할 수 있습니다. 선택은 URL의 화면 설정이고 적재 결과·저장 데이터는 변경하지 않습니다. `?renderer=compare`도 기존 Unity 시작 링크로 호환됩니다.
