# 적재 전략 검증 — 2026-09-22

## 수정한 동작

- 박스·파렛트 모두 사용자가 선택한 전략을 계산과 최종 재검증까지 유지한다.
- 무게중심형은 동일 적재 수량 후보에서 낮은 무게중심·넓은 바닥 배치를 더 강하게 평가한다.
- 공간효율형은 적재량과 공간 활용을 우선하되 얇고 높은 벽 형태를 감점한다.
- 하역순서형은 입력한 배송 순서를 사용하며, 파렛트의 다른 배송지 혼합과 먼저 내릴 화물 위의 늦은 배송지 적층을 막는다.
- 낮은 높이로 다시 계산한 후보도 비교한다. 큰 작업이 전량 적재된 경우 불필요한 전체 EMS 재탐색을 생략하고 낮은 후보 비교를 계속 수행한다.
- 박스 모드의 마지막 잔여 공간 삽입은 경계·충돌·지지·누적 압축·적층·중량·하역 경로를 검사한다.
- 위 파렛트에서 전달되는 하중을 아래 파렛트의 모든 박스 층까지 전달해 검사한다.
- 전량 미적재도 완료된 계산으로 표시하며, 미적재 사유를 열람할 수 있다. 빈 결과에 출하 인증을 부여하지 않는다.
- Unity 내부 공간은 물리 규격과 일치하는 벽으로 구성하며, Meshy 장식 벽의 내부 침범을 제거한다. 박스의 네 옆면에 제품명·박스 코드·수량·중량·치수를 표시한다.

## 결과 해석

이 계산은 여러 결정론적 후보를 비교하는 휴리스틱 최적화다. 모든 3차원 조합의 수학적 전역 최적해를 증명하지 않는다. 잔여 공간 사유는 최종 배치에서 검사한 위치와 안전 조건에 대한 설명이다. 동일 조건에서 세 목표가 일치하면 같은 배치가 선택될 수 있다.

실제 운송의 고정 장치, 포장재 강도, 차량별 축하중은 등록한 제원 및 별도 운송 검증의 적용 범위를 따른다. 이번 수정은 안전 조건을 완화하여 적재량을 늘리지 않는다.
